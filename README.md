# HEAL (Healthy Environment Assist Light)

## 📖 프로젝트 소개
HEAL(Healthy Environment Assist Light)은 공부할 때 주변 환경을 더 편하게 만들어 주는 학습환경 보조 장치입니다.

공부할 때 방이 너무 어둡거나 덥고 답답하면 집중이 잘 안 되는 경우가 많습니다. 하지만 이런 문제는 눈에 바로 보이지 않아 그냥 지나치는 경우가 많습니다.  
그래서 **주변 밝기, 온도, 습도를 측정하여 현재 공부하기 좋은 환경인지 알려주는 장치**를 제작하게 되었습니다.

이 프로젝트를 통해 단순히 센서를 연결하는 것에서 끝나는 것이 아니라,  
실제 생활 속 불편함을 해결하는 발명 아이디어로 발전시킬 수 있다는 점을 배울 수 있었습니다.

---

## ✨ 주요 기능

### 💡 밝기 측정 및 조명 조절
- 조도센서를 이용해 주변 밝기를 측정
- 주변이 어두우면 조명을 더 밝게 조절

### 🌡️ 온도 / 습도 측정
- 온습도센서를 이용해 현재 환경 상태 측정
- 상태를 다음과 같이 표시
  - GOOD
  - NORMAL
  - BAD

### 📟 다양한 출력 방식
측정 결과를 여러 방법으로 확인 가능
- LCD 화면 출력
- 상태 LED 색상 표시
- 스마트폰 앱 연동

### 📱 블루투스 연결
- 블루투스를 이용해 스마트폰과 연결
- 앱에서 현재 상태 확인 가능
  - 밝기
  - 온도
  - 습도
  - 환경 상태

### 🔌 전원 제어 기능
- 전원 ON / OFF 기능 지원
- 더 편리하게 사용할 수 있도록 구성
